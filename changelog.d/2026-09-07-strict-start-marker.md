# fr
Le repère de la mesure de départ s'efface pendant un passage strict. Il restait
posé sur la mesure choisie longtemps après qu'on l'avait dépassée ; il ne marque
plus que le départ du prochain essai, et revient si on arrête le passage.

# en
The start-measure marker clears while a strict run plays. It used to sit on the
chosen measure long after the player had passed it; it now marks only where the
next run begins, and comes back if a run is stopped.
