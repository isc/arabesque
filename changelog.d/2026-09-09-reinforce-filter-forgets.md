# fr
Le filtre « À renforcer » oublie les vieilles fautes. Il lisait des compteurs
cumulés depuis le premier jour, et un morceau massacré il y a six mois y restait
à vie. Il pose maintenant la même question que le mode renforcement : reste-t-il
des mesures à retravailler sur les dix dernières séances ?

# en
The "To reinforce" filter forgets old mistakes. It read counters adding up from
the very first day, so a piece massacred six months ago stayed on the list for
ever. It now asks the same question reinforcement mode does: are there bars
still worth working on over the last ten sessions?
