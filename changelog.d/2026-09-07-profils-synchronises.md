# fr
Chaque profil se synchronise avec le compte. Seul le premier suivait le compte,
les autres restaient sur leur appareil. Un profil créé sur l'iPad apparaît
maintenant sur le téléphone connecté au même compte, avec son journal, ses
statuts et ses doigtés ; supprimé quelque part, il l'est partout.

# en
Every profile syncs with the account. Only the first one followed it, the others
stayed on their device. A profile created on the iPad now shows up on the phone
signed in to the same account, with its journal, statuses and fingerings;
removed anywhere, it is removed everywhere.
