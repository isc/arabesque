# fr
Chaque profil se synchronise avec le compte. Jusqu'ici seul le premier profil suivait le compte, les autres restaient sur leur appareil. Désormais chaque profil a ses propres données sur le serveur, et la liste des profils voyage avec : un profil créé sur l'iPad apparaît sur le téléphone connecté au même compte, avec son journal, ses statuts et ses doigtés ; un profil supprimé quelque part l'est partout.

# en
Every profile syncs with the account. Until now only the first profile followed the account, the others stayed on their device. Each profile now has its own data on the server, and the list of profiles travels along: a profile created on the iPad shows up on the phone signed in to the same account, with its journal, statuses and fingerings; a profile removed anywhere is removed everywhere.
