# fr
Les mesures à renforcer suivent les mains cochées. Main droite seule, seules les
mesures ratées main droite sont proposées, et le bouton l'indique ; à deux mains,
seules celles ratées à deux mains.

# en
Bars to reinforce follow the hands ticked. With the right hand alone, only bars
fumbled right-handed are offered, and the button says so; with both hands, only
those fumbled with both.
