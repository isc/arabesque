# fr
Le clavier d’aide peut être coupé pour de bon. « Ne plus l’afficher », sur le clavier lui-même, le range au-delà de la journée ; le menu ⚙️ le rappelle quand on veut.

# en
The helper keyboard can be turned off for good. “Don’t show again”, on the keyboard itself, puts it away beyond the day; the ⚙️ menu brings it back whenever you want.
