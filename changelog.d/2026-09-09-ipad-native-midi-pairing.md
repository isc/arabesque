# fr
Sur iPad, connecter un clavier ouvre la fenêtre du système. Le bouton
« Connecter clavier MIDI » affichait des instructions pour macOS ; il ouvre
maintenant l'appairage Bluetooth de l'iPad, et le menu ⚙️ le propose aussi.

# en
On iPad, connecting a keyboard opens the system sheet. The "Connect MIDI
keyboard" button used to show macOS instructions; it now opens the iPad's own
Bluetooth pairing, and the ⚙️ menu offers it too.
