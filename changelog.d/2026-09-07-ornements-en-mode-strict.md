# fr
Les ornements se valident en mode strict. Une note ornée n'était jamais attendue :
impossible de la jouer juste. Elle compte maintenant pour sa note écrite, jouée sur
le temps, et le trille ou le mordant qu'on met autour ne coûte plus de fausse note.

# en
Ornaments validate in strict mode. An ornamented note was never expected, so it
could never be played right. It now counts on its written note, struck on the beat,
and the trill or mordent played around it no longer costs a wrong note.
